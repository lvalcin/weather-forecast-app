# Weather Forecast App 🌦️

A weather application built with React that allows users to search for current weather conditions by city. The app fetches real-time data from a weather API and displays temperature, conditions, and location details.

## 🚀 Live Demo
https://lvalcin.github.io/weather-forecast-app/

## 🛠️ Built With
- React
- JavaScript
- HTML5
- CSS3
- OpenWeather API
- GitHub Pages (deployment)

## 📸 Features
- Search weather by city name
- Displays current temperature and weather conditions
- Real-time API data fetching


## 📂 Project Setup

To run this project locally:

```bash
git clone https://github.com/lvalcin/weather-forecast-app.git
cd weather-forecast-app
npm install
npm start
